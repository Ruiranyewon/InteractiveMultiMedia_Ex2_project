# 폰트

`NotoSansKR-ExtraBold-subset.ttf` — Noto Sans KR(ExtraBold)에서 OG 공유 이미지에 쓰이는 글자만 추린 서브셋입니다.
라이선스: SIL Open Font License 1.1 (https://openfontlicense.org). `next/og` 기본 폰트에는 한글이 없어 함께 배포합니다.

OG 이미지에 새 글자를 쓰려면 Google Fonts CSS API의 `text=` 파라미터로 서브셋을 다시 받으세요:
`https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@800&text=<URL-인코딩된 글자>`
